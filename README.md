# Least-Action-Pringciple-Guided-Diffusion
Code for Least-action-principle-guided diffusion model. The paper will be published in Acta Mechanica Sinica.
If you find it helpful to you, please cite: "Zhongxin Yang et al., Least-Action-Guided Diffusion for Physical Extrapolation, Acta Mech. Sin. 43, 361004 (2027)".
And if any questions, feel free to contact me (zhongxinyang@stu.pku.edu).

The data that support the findings of this study are openly available in Science Data Bank at https://doi.org/10.57760/sciencedb.j00145.0003v and https://cstr.cn/31253.11.sciencedb.j00145.0003v.
